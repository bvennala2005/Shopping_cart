**Shopping_cart**
Simple Python Shopping Cart System with Admin and Customer modules, featuring product management, cart operations, total cost calculation, and GST billing through a menu-driven interface.

A beginner-friendly Python project that simulates a basic shopping cart system with separate Admin and Customer functionalities. This project uses Python functions, dictionaries, loops, and conditionals to manage products, cart operations, billing, and GST calculation through a menu-driven interface.

**Features**

**Admin Module**
 Secure admin login
 View available products
 Add new products to the product list

** Customer Module**

  View products
  Add items to cart
  Remove items from cart
  View cart details
  Calculate total cost
  Add GST (18%) to final bill

** Technologies Used**

 Python
 Functions
 Dictionaries
 Loops
 Conditional Statements
